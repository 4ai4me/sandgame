# 모래 뺏기 · Sand Digger

한 기기에서 번갈아 플레이하는 로컬 2인 게임입니다.

[게임 실행](https://4ai4me.github.io/sandgame/)

## 조작과 설정

- 좌클릭을 유지한 채 우클릭하면 채굴을 잠시 멈추고 회전합니다. 우클릭을 놓으면 채굴을 계속하며 좌클릭을 놓으면 수가 끝납니다.
- 바늘은 한 번에 1/10, 이쑤시개는 1/5 알갱이를 깎습니다. 남은 조각은 화면·붕괴·저장·무게에 반영됩니다.
- 6개 도구 선택 버튼과 점수는 게임 화면 안에 있습니다. 모바일 세로·가로 화면에 맞춰 배치하며 한 손가락/두 손가락 안내를 병기합니다.
- 더미 규모는 50~1700(기본 100)입니다. 이는 부피 배율 0.5~17배이며 길이는 부피 배율의 세제곱근만큼, 무게는 부피 배율만큼 변합니다. 계산 격자는 고정하므로 실제 알갱이 개수가 17배가 되는 방식은 아닙니다.
- 마른 모래·고운 모래·젖은 모래·자갈·고운 흙·양토·점토·젖은 점토의 8종은 밀도, 응집력, 마찰, 침식 저항이 다릅니다.
- 낮밤은 2분 주기, 계절은 3분마다, 자동 날씨는 1분마다 바뀝니다. 시간·계절·날씨를 고정할 수도 있습니다. 비·눈·바람·배의 진동이 재질별 붕괴에 영향을 줍니다. 화면 흔들림 옵션은 시각 효과만 끕니다.

- 모래 위에서 왼쪽 버튼을 누르고 있는 동안 계속 채굴합니다. 움직이지 않아도 도구를 사용하며 놓으면 안정화 후 상대 차례가 됩니다. 한 턴 수확량 제한은 없습니다.
- 오른쪽 버튼을 누른 채 이동하면 카메라가 회전합니다. 휠·＋/−는 확대·축소, 방향키는 회전입니다.
- 빗자루, 손가락, 바늘, 이쑤시개, 한손, 양손은 범위·깊이·속도가 다릅니다. 커서도 선택한 도구 모양으로 바뀝니다.
- 터치 한 손가락은 채굴, 두 손가락은 회전·핀치 확대입니다. 두 손가락 전환이나 포인터 취소 시 미확정 채굴을 되돌립니다.
- 새 경기에서 총 플레이 시간과 턴 시간을 직접 입력하고 초·분·시간 단위를 선택합니다. 0은 무제한, 최대 24시간이며 환산 결과는 정수 초여야 합니다.
- 턴 제한에 도달하면 진행 중인 도구 사용을 끝냅니다. 전체 시간이 끝나면 양쪽 행동 수를 맞추는 마지막 대응 턴 후 무게를 비교합니다.
- 단면 보기로 내부를 확인합니다. 도움말·설정·숨겨진 페이지에서는 경기 시계가 멈춥니다.

## 배경·음악·깃발

해변, 놀이터, 씨름장, 바다 위 배, 강 위 배, 사막, 정원, 학교 운동장, 마을, 채석장, 숲, 유적의 12곳을 단순한 블록으로 구성했습니다. 장면 전체가 같은 픽셀별 깊이 버퍼를 사용해 객체의 그리기 순서에 따른 겹침을 방지합니다.

각 장소에 다른 오리지널 합성 배경음악을 연결했습니다. 첫 사용자 조작 후 재생되며 음악·효과음·음량을 조절할 수 있습니다. 외부 이미지·음원·라이브러리가 필요하지 않습니다.

원피스의 밀짚모자·하트·빨간머리·흰수염·검은수염·로저·버기·태양 해적단을 표현한 간략화 문양 8종을 직접 그렸습니다. 공식 이미지 파일은 사용하지 않았습니다. 새 경기에서는 직전과 다른 문양을 선택합니다.

깃대는 나뭇가지·젓가락·쇠막대·당구 큐·대나무·플라스틱 중 재질을 고르고 색상, 굵기, 길이, 초기 각도, 매립 깊이를 무작위로 정합니다. 재질과 치수는 지지력에 반영됩니다. 같은 시드는 같은 모래 언덕을 만들지만 깃발은 새 경기마다 달라집니다.

매립 깊이는 더미 최고 높이의 최소 1/7부터 바닥까지입니다. 깊게 매립하는 경우를 포함한 분포로 평균 3/7 이상을 목표로 합니다. 지지 판정은 밑동 주변만이 아니라 매립된 깃대 전체를 검사합니다. 아래를 파더라도 위쪽 매립부가 충분히 지지하면 넘어지지 않습니다.

## 규칙과 저장

- 기본 규모의 마른 모래 1개는 0.7g입니다. 실제 수확 무게에는 잔여 비율·재질 밀도·부피 배율을 반영합니다. 내부 점수는 정수 마이크로그램으로 저장해 부분 채굴 누적 오차를 방지합니다. 붕괴로 떨어진 재료에는 점수가 없습니다.
- 지지를 잃은 깃발의 노출된 부분이 모래나 바닥에 닿으면 마지막 행동자가 패배합니다. 처음부터 묻힌 부분은 패배 접촉에서 제외합니다.
- 확정 턴은 현재 브라우저에 자동 저장합니다. 저장 실패 시 미확정 행동을 복구하고 오류를 표시합니다.
- 구버전 저장의 지형·점수·턴·시간·이전 물리를 보존합니다. 구버전 원문을 남긴 채 새 형식으로 저장합니다. 손상된 저장은 검증 없이 덮어쓰지 않습니다.
- 새 재질·부분 채굴·환경 규칙은 새 경기부터 적용됩니다. 조작하지 않는 동안 환경 변화로 깃발이 쓰러지면 특정 플레이어에게 책임을 돌리지 않고 무승부로 종료합니다.

## 실행과 검증

최상위 index.html이 게임의 원본 진입점입니다. 저장소 루트에서 python -m http.server 8765를 실행하고 http://localhost:8765/에 접속합니다. GitHub Pages도 루트에서 바로 게임을 제공합니다. 로컬 파일로 열 경우 저장은 브라우저 정책에 따라 제한될 수 있습니다.

node build.cjs는 자산 경로를 검사하고 Sites용 dist/index.html을 생성합니다. dist/index.html은 직접 편집하지 않습니다. Sites가 dist를 정적 디렉터리로 사용하므로 원본을 루트에 두면서 배포용 사본을 유지합니다.

검증 명령: node tests.cjs, node expansion-tests.cjs, node materials-tests.cjs.

기존 48개는 구버전 물리 계약과 현재 입력·저장·배경·음악을 보호합니다. 새 27개는 부분 질량 보존, 재질별 붕괴, 700개 시드 매립 분포, 동시 버튼 입력, 깊이 버퍼의 순서 독립성, 교차 면의 픽셀별 가림, 모바일 크기의 렌더 경로를 검사합니다. 어댑터 및 래스터 계산 검사이며 실제 브라우저 화면 배치·음질·모바일 기기 성능을 검증한 것은 아닙니다.

- dist/content.js: 장소·음악·깃발·깃대 재질 목록. 향후 콘텐츠 추가 진입점.
- dist/world.js: 장소별 블록 배치, 깃발 문양, 도구 커서.
- dist/audio.js: 음악과 효과음 합성.
- dist/engine.js: 복셀 물리, 규칙, 저장 검증·호환 처리.
- dist/game.js: 화면, 입력, 타이머, 로컬 저장.
- dist/materials.js: 재료 8종의 게임용 계수.
- dist/renderer.js: 장면과 깃발에 공통으로 적용하는 픽셀별 깊이 렌더러.
- dist/engine-v2.js: 기존 저장용 물리 계약 보존.

25 × 17 × 25 계산 격자와 Canvas 렌더러를 사용합니다. 마찰·응집력·습윤 효과는 게임용 단순화 계수이며 지반공학 실측 모델이나 완전한 강체·모래 알갱이 시뮬레이션은 아닙니다. 온라인 대전·로그인·방 서버·다기기 동기화는 포함하지 않습니다. 선택적으로 WebMCP 경기 읽기·도구 선택을 제공합니다.
