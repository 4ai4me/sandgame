# 모래 뺏기 · Sand Digger

기획서 17장 MVP를 바탕으로 제작한 브라우저용 로컬 2인 게임입니다.

## 실행

`dist/index.html`을 Chrome 또는 Edge에서 엽니다. 별도 설치나 인터넷 연결 없이 게임을 실행할 수 있습니다. 브라우저의 로컬 파일 저장 정책에 따라 자동 저장이 제한될 수 있으므로, 저장 상태를 확인하세요. HTTP 서버로 실행하면 같은 주소에서 안정적으로 이어하기를 사용할 수 있습니다.

## 조작

- 붓, 손가락, 손 중 도구를 선택하고 모래 위를 누른 채 드래그합니다.
- 놓거나 도구별 채굴량이 소진되면 안정화 후 상대 차례가 됩니다.
- 우클릭 드래그 또는 ‘시점 회전’ 버튼: 카메라 회전. 휠과 ＋/−: 확대·축소.
- 모바일 한 손가락: 채굴. 두 손가락: 회전·핀치 확대. 두 번째 손가락을 놓으면 채굴 중이던 미확정 행동을 취소하고 카메라로 전환합니다.
- ‘단면 보기’는 지형의 절반을 숨겨 내부를 확인합니다. 양쪽 모두 사용 가능합니다.
- 카메라는 캔버스에 초점을 맞춘 뒤 방향키 및 ＋/−로도 조작할 수 있습니다.
- ‘새 경기’에서 경기 시간·턴 시간·시드를 설정합니다. 같은 시드는 같은 언덕과 깃발을 만듭니다.

## 규칙

- 제거한 복셀은 수확함으로 이동하며 1개당 0.7g을 인정합니다. 붕괴로 낙하한 모래는 점수를 주지 않습니다.
- 도구별 한 수의 최대 수확량은 붓 36개, 손가락 70개, 손 150개입니다.
- 깃발이 지지를 잃으면 회전·낙하합니다. 모래 또는 바닥과 접촉한 경우 마지막 행동자가 패배합니다. 위험 지표 또는 기울기만으로 승패를 결정하지 않습니다.
- 시간이 끝나면 진행 중인 행동과 안정화를 마치고, 필요하면 후공에게 마지막 대응 턴을 줍니다. 두 사람의 행동 수가 같아지면 표시 무게로 판정하며 같으면 무승부입니다.
- 턴 제한 시간 초과는 자동 패스입니다. 페이지를 숨기거나 도움말·설정을 연 동안 경기 시계는 멈춥니다. 서버 기준의 24시간 비동기 경기는 아닙니다.
- 확정 턴은 이 브라우저에 자동 저장합니다. 저장 실패 시 채굴 전으로 복구합니다. 손상된 데이터는 읽기 검증을 거치며 새 경기 시작 전까지 덮어쓰지 않습니다.

## 구현과 한계

- 25 × 17 × 25의 3차원 복셀 격자와 직교 투영 Canvas 렌더러. 높이맵이 아니므로 터널·빈 공간·천장을 보존합니다.
- 각 층은 아래 복셀 또는 최대 2칸의 옆 지지를 통해 유지됩니다. 지지되지 않은 복셀은 아래로 낙하합니다. 실제 건조 모래의 연속체 역학이나 개별 알갱이 물리 대신, 결정적인 단순화 규칙을 사용합니다.
- 깃발 지지 영역의 잔존량과 접촉으로 안정 상태를 계산하고, 무너질 때 별도의 회전·낙하 및 접촉 검사를 합니다. 완전한 강체 물리 엔진은 아닙니다.
- 조작 판정은 고정 격자에서 진행합니다. 고배율의 점무늬는 시각 표현이며 한 알 단위 정밀 시뮬레이션이 아닙니다.
- 외부 이미지·음원·라이브러리 의존성이 없습니다. 음악은 이 게임을 위해 작성한 합성 멜로디이며 Web Audio로 생성합니다.
- 온라인 대전·랭킹·계정·다기기 동기화·모바일 앱 패키지는 기획서 MVP 제외 항목으로 구현하지 않았습니다.
- 실제 모바일 기기 성능 및 브라우저 화면 배치 검증은 별도로 필요합니다. 마우스/터치 처리는 구현되어 있습니다.

## 개발 검증

`node tests.cjs`로 규칙, 재현성, 터널, 붕괴, 질량 보존, 전도 접촉, 저장 검증, 실제 UI 컨트롤러의 입력·복구 흐름을 확인합니다. UI 테스트는 DOM/Canvas 어댑터로 실행하며 실제 브라우저의 시각 검증을 대체하지 않습니다.

`dist/engine.js`: 결정적 물리·규칙·저장 데이터 검증. `dist/game.js`: 화면·입력·오디오·로컬 저장. `dist/style.css`: 반응형 UI.

선택적으로 WebMCP가 있는 환경에서는 경기 읽기 및 도구 선택을 제공합니다. 미지원 브라우저에서도 게임은 동작합니다.
