# 모래 뺏기 · Sand Digger

한 기기에서 번갈아 플레이하는 로컬 2인 게임입니다.

[게임 실행](https://4ai4me.github.io/sandgame/)

## 조작과 설정

- 모래 위에서 왼쪽 버튼을 누르고 있는 동안 계속 채굴합니다. 움직이지 않아도 도구를 사용하며 놓으면 안정화 후 상대 차례가 됩니다. 한 턴 수확량 제한은 없습니다.
- 오른쪽 버튼을 누른 채 이동하면 카메라가 회전합니다. 휠·＋/−는 확대·축소, 방향키는 회전입니다.
- 빗자루, 손가락, 바늘, 이쑤시개, 한손, 양손은 범위·깊이·속도가 다릅니다. 커서도 선택한 도구 모양으로 바뀝니다.
- 터치 한 손가락은 채굴, 두 손가락은 회전·핀치 확대입니다. 두 손가락 전환이나 포인터 취소 시 미확정 채굴을 되돌립니다.
- 새 경기에서 총 플레이 시간과 턴 시간을 직접 입력하고 초·분·시간 단위를 선택합니다. 0은 무제한, 최대 24시간이며 환산 결과는 정수 초여야 합니다.
- 턴 제한에 도달하면 진행 중인 도구 사용을 끝냅니다. 전체 시간이 끝나면 양쪽 행동 수를 맞추는 마지막 대응 턴 후 무게를 비교합니다.
- 단면 보기로 내부를 확인합니다. 도움말·설정·숨겨진 페이지에서는 경기 시계가 멈춥니다.

## 배경·음악·깃발

해변, 놀이터, 씨름장, 바다 위 배, 강 위 배, 사막, 정원, 학교 운동장, 마을, 채석장, 숲, 유적의 12곳을 단순한 블록으로 구성했습니다. 배 위의 화면 흔들림은 설정에서 끌 수 있으며 물리와 점수에는 영향을 주지 않습니다.

각 장소에 다른 오리지널 합성 배경음악을 연결했습니다. 첫 사용자 조작 후 재생되며 음악·효과음·음량을 조절할 수 있습니다. 외부 이미지·음원·라이브러리가 필요하지 않습니다.

원피스의 밀짚모자·하트·빨간머리·흰수염·검은수염·로저·버기·태양 해적단을 표현한 간략화 문양 8종을 직접 그렸습니다. 공식 이미지 파일은 사용하지 않았습니다. 새 경기에서는 직전과 다른 문양을 선택합니다.

깃대는 나뭇가지·젓가락·쇠막대·당구 큐·대나무·플라스틱 중 재질을 고르고 색상, 굵기, 길이, 초기 각도, 매립 깊이를 무작위로 정합니다. 재질과 치수는 지지력에 반영됩니다. 같은 시드는 같은 모래 언덕을 만들지만 깃발은 새 경기마다 달라집니다.

## 규칙과 저장

- 제거한 복셀 1개당 0.7g을 수확합니다. 붕괴로 떨어진 모래에는 점수가 없습니다.
- 지지를 잃은 깃발의 노출된 부분이 모래나 바닥에 닿으면 마지막 행동자가 패배합니다. 처음부터 묻힌 부분은 패배 접촉에서 제외합니다.
- 확정 턴은 현재 브라우저에 자동 저장합니다. 저장 실패 시 미확정 행동을 복구하고 오류를 표시합니다.
- 구버전 저장의 지형·점수·턴·시간·이전 물리를 보존합니다. 구버전 원문을 남긴 채 새 형식으로 저장합니다. 손상된 저장은 검증 없이 덮어쓰지 않습니다.

## 실행과 검증

dist/index.html을 직접 열거나 저장소 루트에서 python -m http.server 8765를 실행하고 http://localhost:8765/dist/에 접속합니다. 로컬 파일 모드의 저장은 브라우저 정책에 따라 제한될 수 있습니다.

검증 명령: node tests.cjs 및 node expansion-tests.cjs.

기존 23개와 확장 25개 테스트는 물리·터널·질량 보존·입력·타이머·저장 실패·실제 구버전 저장 복구·배경 및 음악 생성 흐름을 검사합니다. DOM/Canvas/Web Audio 어댑터 테스트이며 실제 브라우저 화면 배치·음질·모바일 성능을 검증한 것은 아닙니다.

- dist/content.js: 장소·음악·깃발·깃대 재질 목록. 향후 콘텐츠 추가 진입점.
- dist/world.js: 장소별 블록 배치, 깃발 문양, 도구 커서.
- dist/audio.js: 음악과 효과음 합성.
- dist/engine.js: 복셀 물리, 규칙, 저장 검증·호환 처리.
- dist/game.js: 화면, 입력, 타이머, 로컬 저장.

25 × 17 × 25 복셀과 Canvas 렌더러를 사용합니다. 단순화된 물리이며 완전한 강체·모래 알갱이 시뮬레이션은 아닙니다. 온라인 대전·로그인·방 서버·다기기 동기화는 포함하지 않습니다. 선택적으로 WebMCP 경기 읽기·도구 선택을 제공합니다.
